# *Ms4300_Digital_Library*
Thesis project in italian, english and french for the Bologna University's course "Scienze del libro e del documento", based on a 4-months intern in the Bordeaux Municipal Library

## Sources
The main sources of this project are the documents of the archive called MS4300 or "Itié-Latresne" of the Bordeaux Municipal Library, in France. Every information used in this repository comes from that archive, which the author had the possibility to read during an internship made from february to may 2026. Other sources had been used to complete the informations of the archive, mostly taken from the websites [Man8rove](https://man8rove.com/fr/home/), [Wikidata](https://www.wikidata.org/wiki/Wikidata:Main_Page) and few others. Also, many informations have been found in books and other documents read during the stay in Bordeaux, which are cited in the [Bibliography].
