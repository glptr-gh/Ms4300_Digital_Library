# _CSV_Directory_
This directory was made to store the files in `.csv` format, mostly created during the staying in Bordeaux, in `.xlxs` format, based on the datas found in the ITIE-LATRESNE archive, and modified later, after the return to Italy. This is the core of the repository, because it's here where the Digital Library takes the datas to work. The files are named after their version, uploaded to show the process of refining and changing behind the final version of each database.
