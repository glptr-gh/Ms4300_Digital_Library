# _RDF_Directory_
This is the directory used to store the files in `.ttl` format. It contains other three directories:
1. **documenti**: for the documents of the ITIE-LATRESNE archive and all the informations linked to them;
2. **matrimoni**: for the file which expresses the marriages of the people mentioned in the documents in RDF;
3. **persone**: for the people mentioned in the documents
