# *Data Directory*
This Directory is the main destination for all the datas produced during the research, in many different forms. Here will be stored the main database, containing all the informations taken from the samples used in the Bordeaux Meriadeck Library, the dates, the names found in the documents and the photos of them. At the same time, here will be stored other kinds of datas, produced after the consultation of the documents, during the creation of the digital library, such as the tiles of the images for IIIF, the manifests, the triples RDF made to create LODs, the transcription in XML-TEI of certain documents.

## Contents
- [CSV directory](./CSV/): here will be stored all the files in '''.csv''' format, like the main database. This is the heart of the project, and the structure that will feed the digital library;
- [XML directory](./XML/): this directory will be used for the transcriptions of selected documents, written in '''XML-TEI''' language;
- [RDF directory](./RDF/): this is the place where all the files for the LODs will be stored;
- [Images directory](./Imgs/): mostly in '''.jpg''', all the images of the project will be put inside this directory.
- [IIIF_directory](./IIIF): this directory will be used mainly to store the manifests and the tiles of the photos of the documents.
