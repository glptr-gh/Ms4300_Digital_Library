# *Data Directory*

## Contents
- [CSV directory](CSV): here will be stored all the files in '''.csv''' format
- [XML directory](XML): this directory will be used for the transcriptions of selected documents, written in XML-TEI language
- [RDF directory](RDF): this is the place where all the files for the creation of LODs will be stored
- [Images directory](Imgs): mostly in '''.jpg''' and '''.tiff''', all the images of the project will be put inside this directory
